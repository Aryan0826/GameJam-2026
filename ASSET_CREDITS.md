The arena and flag use Godot primitives. The 3D pawns are built from a revolved profile defined in `scripts/board.gd`. Godot draws the cracks, status markers, and movement previews. The project uses zero generative media assets. A copy of the asset credits is accessible from the game's footer.

The workspace retains femrek's CC0 [pawn sprite](https://opengameart.org/content/chess-pieces-in-svg-format) from the 2D release. The current release uses the 3D meshes.
