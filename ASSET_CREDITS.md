The beveled landing pads are built with a mesh defined in `scripts/board.gd`. The cockpit frame, patrol silhouette, envoy portrait, chart, cracks, status markers, and movement previews are drawn with Godot primitives. The project uses zero generative media assets. A copy of the asset credits is accessible from the game's footer.

The workspace retains femrek's CC0 [pawn sprite](https://opengameart.org/content/chess-pieces-in-svg-format) from the 2D release. The current release uses the 3D meshes.
